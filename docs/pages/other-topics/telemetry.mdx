sidebar_label: Telemetry

DevPod doesn't collect telemetry. The CLI and the desktop app don't send any usage data.

Upstream DevPod sent CLI usage events to Loft, its original maintainer. This fork removed that, together with the
`TELEMETRY` context option and the `DEVPOD_DISABLE_TELEMETRY` environment variable, which are no longer needed.
If telemetry is added back in the future, this page will describe what is collected and how to opt out.
