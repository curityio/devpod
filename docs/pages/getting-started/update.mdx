## DevPod Desktop

DevPod desktop automatically checks for updates on GitHub every 15minutes.
When an update will be available this popup will appear to confirm the update process:

<figure>
  <img src={require("@site/static/media/devpod-update-available.png").default} alt="DevPod Flow" />
  <figcaption>Create Workspace</figcaption>
</figure>

The update will continue in background. When it's done you'll be prompted to restart the application.

<figure>
  <img src={require("@site/static/media/devpod-update-done.png").default} alt="DevPod Flow" />
  <figcaption>Create Workspace</figcaption>
</figure>

At restart the application will be at latest version.

## DevPod Desktop - alternative

If you installed DevPod using deb or rpm packages, you'll need to [download the
new package](https://github.com/curityio/devpod/releases/latest/), and install it using your package manager again.

## Optional: Update DevPod CLI

`devpod upgrade` replaces the CLI with the newest stable release, if it is newer than yours:

```sh
devpod version                         # the version you have
devpod upgrade --dry-run               # is there a newer one, and could this user replace the CLI?
sudo devpod upgrade                    # upgrade, when the CLI is in a directory you can't write to
devpod upgrade --version v0.8.0        # install another release
```

See [Upgrade DevPod CLI](./install.mdx#upgrade-devpod-cli) for the details. After an upgrade, a workspace created by
an older version keeps working, and DevPod warns when it replaces the agent in its dev container. To give the
workspace the new version's setup, recreate it:

```sh
devpod up my-workspace --recreate
```
