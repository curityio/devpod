This project is a hard fork of [loft-sh/devpod](https://github.com/loft-sh/devpod), maintained by [Curity](https://curity.io/).

## Reporting An Incident

Please follow the instructions in [SECURITY.md](SECURITY.md) to report a security incident. **Please do not report incidents via public issues.**
